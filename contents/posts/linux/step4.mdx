# パスの概念

//画像を追加

ファイルを開いたり、コマンドを実行したりするには、そのファイルやコマンドの場所を正確に指定しないといけません。この指定方法をパスと呼びます。

## パスの書き方

パスはドット「.」とスラッシュ「/」で表現します。

// 画像

例えば画像のルートディレクトリからtarouディレクトリまでをパスでかくと

`./home/tarou`

と表示できます。

```php
| パス | 意味|
|--------------|------|
| ./ | 現在の場所を表しています |
| ../  | 今いる場所から1つ上の階層を表しています |
| /ディレクトリ名  | 各種設定ファイルなどさまざまなファイルが保管される場所です。 |
```

# ホームディレクトリ

~「チルダ」はホームディレクトリを表しますルートディレクトリを表す「/」などと同様にパスの指定に使用できます。

<Note>

```php
| 記号 | 呼び方 | 使い所 |
|--------------|------|------|
| , | カンマ |文章や単語の区切り|
| . | ドット |文章や単語の終わり |
| - | ハイフン |単語ごとの区切り|
| _ | アンダースコア | 単語ごとの区切り |
| : | コロン |単語の終わり|
| ; | セミコロン | 単語の終わり |
```
