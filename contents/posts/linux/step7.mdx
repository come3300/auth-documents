## vimとは

{/* TODO 画像を作成する */}

Vimは、Unix系OSで広く使われている高機能なテキストエディタです。
Vi IMprovedの略称で、元となった「vi」エディタを改良・拡張したものです。

### Vimの特徴

- **キーボードのみで操作可能**: マウスを使わずにすべての操作ができるため、慣れると非常に高速に編集作業ができます
- **軽量で高速**: リモートサーバーなど、リソースが限られた環境でも快適に動作します
- **カスタマイズ性が高い**: プラグインや設定ファイル（.vimrc）で自分好みにカスタマイズできます
- **どこでも使える**: ほぼすべてのUnix系OSに標準でインストールされています

💡 最初は操作が難しく感じるかもしれませんが、慣れると非常に効率的な編集作業ができるようになります！

## 起動方法

### 新規ファイルの作成・編集

```bash

`vim ファイル名`
```

```bash
`vim test.txt
*# test.txtファイルをVimで開きます（存在しない場合は新規作成）*`
```
### 既存ファイルの編集

```bash
`vim sample.txt
*# 既存のsample.txtファイルを開いて編集します*`
```
### 特定の行から開く

```bash
`vim +10 sample.txt
*# sample.txtの10行目から開きます*

vim + sample.txt
*# ファイルの最終行から開きます*`
```

## 各モードについて

{/* TODO 画像を作成する */}

Vimには複数のモードがあり、モードによって操作が異なります。これがVimの最大の特徴です。

### ノーマルモード（Normal Mode）

Vimを起動すると最初にこのモードになります。カーソル移動、テキストの削除、コピー、ペーストなどの操作を行います。

**特徴:**

- 文字入力はできません
- コマンドを実行するモードです
- 他のモードから `Esc` キーを押すことで戻れます

### インサートモード（Insert Mode）

実際に文字を入力・編集するモードです。

**インサートモードへの入り方:**

```
コマンド動作iカーソルの位置から入力開始I行の先頭から入力開始aカーソルの次の位置から入力開始A行の末尾から入力開始oカーソルの下に新しい行を作成して入力開始Oカーソルの上に新しい行を作成して入力開始
```

**ノーマルモードへ戻る:**

- `Esc` キーを押す

### ビジュアルモード（Visual Mode）

テキストを選択するモードです。選択した範囲に対してコマンドを実行できます。

**ビジュアルモードへの入り方:**

```
コマンド動作v文字単位で選択V行単位で選択Ctrl + v矩形選択（ブロック選択）
```

### コマンドラインモード（Command-line Mode）

保存、終了、検索、置換などの高度な操作を行うモードです。

**コマンドラインモードへの入り方:**

- ノーマルモードで `:` を入力

> ⚠️ 重要: Vimで最も混乱するのがモードの切り替えです。困ったら Esc キーを数回押してノーマルモードに戻りましょう！
>

## 基礎コマンド

### カーソル移動（ノーマルモード）

### 基本移動

```bash

`h  *# 左へ移動*
j  *# 下へ移動*
k  *# 上へ移動*
l  *# 右へ移動*`
```
### 単語単位の移動

```bash

`w  *# 次の単語の先頭へ移動*
b  *# 前の単語の先頭へ移動*
e  *# 次の単語の末尾へ移動*`
```
### 行内での移動

```bash

`0  *# 行の先頭へ移動*
^  *# 行の最初の非空白文字へ移動*
$  *# 行の末尾へ移動*`
```
### ページ単位の移動

```bash

`gg   *# ファイルの先頭へ移動*
G    *# ファイルの末尾へ移動*
10G  *# 10行目へ移動*
Ctrl + f  *# 1ページ下へ移動*
Ctrl + b  *# 1ページ上へ移動*`
```
### テキストの削除（ノーマルモード）

```bash

`x   *# カーソル位置の1文字を削除*
dd  *# 1行削除*
dw  *# 1単語削除*
D   *# カーソル位置から行末まで削除*
3dd *# 3行削除（数字を前につけると繰り返し）*`
```
### コピーとペースト（ノーマルモード）

```bash

`yy  *# 1行コピー（ヤンク）*
yw  *# 1単語コピー*
p   *# カーソルの後にペースト*
P   *# カーソルの前にペースト*
3yy *# 3行コピー*`
```
### アンドゥとリドゥ

```bash

`u      *# 元に戻す（Undo）*
Ctrl + r  *# やり直し（Redo）*`
```
### ビジュアルモードでの操作

```bash

`v      *# ビジュアルモード開始# 移動キーで範囲選択*
y      *# 選択範囲をコピー*
d      *# 選択範囲を削除*`
```

## 検索と置換

### 検索

### 前方検索

```bash

`/検索文字列
*# Enterキーで検索実行*`
```
```bash

`/hello
*# "hello"という文字列を検索します*`
```
### 後方検索

```bash

`?検索文字列
*# Enterキーで検索実行*`
```
### 検索結果の移動

```bash

`n  *# 次の検索結果へ移動*
N  *# 前の検索結果へ移動*`
```
### 検索のハイライトを消す

```bash

`:noh
*# または*
:nohlsearch`
```
### 置換

### 基本的な置換

```bash

`:s/置換前/置換後/
*# カーソル行の最初の一致を置換*`
```
```bash

`:s/old/new/
*# カーソル行の"old"を"new"に置換（最初の1つのみ）*`
```
### 1行内のすべてを置換

```bash

`:s/置換前/置換後/g`
```
```bash

`:s/old/new/g
*# カーソル行のすべての"old"を"new"に置換*`
```
### ファイル全体を置換

```bash

`:%s/置換前/置換後/g`
```
```bash

`:%s/apple/orange/g
*# ファイル全体の"apple"を"orange"に置換*`
```
### 確認しながら置換

```bash

`:%s/置換前/置換後/gc`

各置換ごとに確認メッセージが表示されます：

- `y`: この置換を実行
- `n`: この置換をスキップ
- `a`: 以降すべて置換
- `q`: 置換を終了
```
### 特定の行範囲で置換

```bash

`:10,20s/old/new/g
*# 10行目から20行目まで置換*

:.,+5s/old/new/g
*# 現在行から5行下まで置換*`
```

## 保存コマンド

### 基本の保存と終了

```bash

`:w
*# ファイルを保存（Write）*`
```
```bash

`:q
*# Vimを終了（Quit）# ※保存していない変更がある場合はエラーになります*`
```
```bash

`:wq
*# 保存して終了# または*
:x
*# 同じく保存して終了（変更がある場合のみ保存）*`
```
```bash

`:q!
*# 保存せずに強制終了# ※変更内容は破棄されます*`
```
### その他の保存コマンド

```bash

`:w ファイル名
*# 指定したファイル名で保存（名前をつけて保存）*`
```
```bash

`:w test2.txt
*# test2.txtという名前で保存*`
```
```bash

`:w!
*# 強制的に上書き保存（読み取り専用ファイルの場合など）*`
```
```bash

`ZZ
*# ノーマルモードで保存して終了（:wqと同じ）# ※コマンドラインモードに入らずに実行できます*`
```
```bash

`ZQ
*# ノーマルモードで保存せずに終了（:q!と同じ）*`
```
### 特定範囲の保存

```bash

`:10,20w newfile.txt
*# 10行目から20行目までをnewfile.txtに保存*`
```

## 実践問題

1. Vimで新しいファイル`practice.txt`を作成してください
2. インサートモードに入り、5行程度の文章を入力してください
3. ノーマルモードに戻り、3行目にジャンプしてください
4. その行をコピーして、ファイルの末尾にペーストしてください
5. ファイル内の特定の単語を検索してください
6. その単語を別の単語に置換してください（確認しながら）
7. ファイルを保存して終了してください

> 💡 Vimを終了できない時は: Escキーを押してから:q!と入力してEnterキーを押すと、保存せずに終了できます！
