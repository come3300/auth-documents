## MySQLとは

**Oracleが開発・サポートするオープンソースのリレーショナルデータベース管理システム（RDBMS）**です。行と列で構成されるテーブルにデータを整理・管理し、[SQL](https://www.google.com/search?q=SQL&rlz=1C5CHFA_enJP1059JP1059&oq=mysql%E3%81%A8%E3%81%AF&gs_lcrp=EgZjaHJvbWUyBggAEEUYOdIBCTQwMDlqMGoxNagCCLACAQ&sourceid=chrome&ie=UTF-8&ved=2ahUKEwj8_f-kuYGRAxUvsVYBHdRtAl8QgK4QegYIAQgAEAY)（[Structured Query Language](https://www.google.com/search?q=Structured+Query+Language&rlz=1C5CHFA_enJP1059JP1059&oq=mysql%E3%81%A8%E3%81%AF&gs_lcrp=EgZjaHJvbWUyBggAEEUYOdIBCTQwMDlqMGoxNagCCLACAQ&sourceid=chrome&ie=UTF-8&ved=2ahUKEwj8_f-kuYGRAxUvsVYBHdRtAl8QgK4QegYIAQgAEAc)）という言語を使って
データの検索、操作、管理を行います。
WordPressのようなウェブアプリケーションなど、さまざまな場面で広く使われており、高速なパフォーマンス、強力なセキュリティ、高い拡張性が特徴です。

# phpMyadminとは

phpMyAdminとは、MySQLをWebブラウザ上で管理するためのアプリケーションです。phpMyAdminを使えばGUI上で、MySQLを操作することができます。

まずはこのphpMyadminを使ってGUI上でデータベースの操作をおこない、DB,SQL慣れていきましょう！

# 環境構築

今回はphpMyadmin環境をDockerを用いて構築します。

まずは以下のリポジトリをcloneしてみましょう！

https://github.com/come3300/practice-sql

## 環境構築手順

```php
// cloneしたいディレクトリに移動して
git clone https://github.com/come3300/practice-sql.git
cd practice-sql
docker compose up -d
```

上記コマンドを1行ずつ順に実行して

`http://localhost:8080`

こちらにアクセスしてみましょう。
