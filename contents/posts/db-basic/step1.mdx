# DBとは

データベースとは検索や書き換え、分析などのデータ管理を目的として様々な情報を蓄積したものです。
電話帳や会員名簿のように紙に記録されているものもデータベースといえますが、特にITの世界では、電子的な媒体にファイルなどの形式で保存・蓄積したものを指します。


## RDB

現在、分野を問わず広く用いられているのが、複数の表の形式でデータを管理するリレーショナルデーターベース(RDB)です。

## DBMS

データベースは単なる情報の集まりに過ぎません。その実体はファイルです。
したがって、ファイルに対して SQL で書かれた命令を送っても、検索や書き換えは
できるわけではありません。

ではどうすれば SQL を送ると処理が行われるのでしょうか。
結論から言えば、データベースファイルではなく、データベース管理システム
（DBMS: Database Management System）と呼ばれるプログラムに対して SQL
を送信します。DBMS はコンピュータ上で常に稼働していて SQL を受け取り、その解析・
SQL の内容に従って、データベースファイルの内容を検索したり、書き換えたり
する処理を実行してくれます

# SQLとは

**リレーショナルデータベース（RDB）のデータを操作するための標準化されたデータベース言語**です。SQLを使うことで、データの検索、挿入、更新、削除といった操作や、データベース自体の作成・変更・権限管理を行うことができます。多くのデータベースシステムで共通して利用できるのが特徴です。
