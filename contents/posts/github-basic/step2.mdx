## 環境構築しよう
githubをPCで使えるように、必要な設定を行っていきましょう。

## Macの方はこちらから
### Gitをダウンロードしよう

まずは皆さんのPCにgitがインストールされているか確認してみましょう。

```
$ git --version
```

このように入力してみて

```
git version 2.30.1
```

このように表示されたらgitがインストールされています。
その場合は以降スキップしてもらって問題ありません。

### Gitのインストール方法

もしインストールされていない場合は下記のリンクからダウンロードしてください。

https://git-scm.com

①「Download for Mac」をクリック。

![Photo by Minh Pham](/images/documents/tutorial/git-Mac-dl1.png)

②Binnary Installer を選択し、ディスクイメージを入手する。

![Photo by Minh Pham](/images/documents/tutorial/git-Mac-dl2.png)

Githubへ登録
Githubアカウントをまだ持ってない方は下記リンクからアカウント作成をしてみましょう。
※アカウント作成の際に使用した情報は忘れずにメモしておいてください。

Git のインストール
Git のディスクイメージに収納されているpkgファイルをダブルクリックしてインストールする。

![Photo by Minh Pham](/images/documents/tutorial/git-Mac-dl3.png)

インストールの確認

```

このように入力してみて

```

4. GitHub にSSH接続
SSHで利用する認証用の鍵を生成する。

🖥️ terminal

```
$ # SSHの公開鍵と秘密鍵を作成
$ ssh-keygen -t ed25519 -C "foo@example.com"

$ # 生成した公開鍵をクリップボードにコピー
$ pbcopy < ~/.ssh/id_ed25519.pub
```

①GitHub のサイトより公開鍵の登録画面を開く。
下記をクリックしてみましょう
https://github.com/settings/ssh/new

②クライアントの公開鍵を登録する。
先ほどの①をクリックすると下記のような画面が表示されると思います。

![Photo by Minh Pham](/images/documents/tutorial/git-Mac-dl4.png)

③SSH接続のオプション等を設定して接続確認を行う。（※詳細は公式ガイドを参照）

🖥️ terminal

```
$ # SSH設定ファイルの作成（または追記）
$ cat <<EOF >> ~/.ssh/config
Host *.github.com
AddKeysToAgent yes
UseKeychain yes
IdentityFile ~/.ssh/id_ed25519
EOF

$ # パスフレーズをキーチェーンに格納
$ ssh-add --apple-use-keychain ~/.ssh/id_ed25519

$ # SSH接続確認
$ ssh -T git@github.com
```

接続に成功すると以下のように表示される。

```
Hi foo! You've successfully authenticated, but GitHub does not provide shell access.
```
